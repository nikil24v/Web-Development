Flex Sizing Explained Simply

1. flex-basis (Default Size)
flex-basis sets the initial size of a flex item before it grows or shrinks. Think of it as the "starting size" you give each item.

2. flex-grow (Expanding)
flex-grow controls how much an item expands when there's extra space. Higher number = grows more. Default is 0 (doesn't grow).
Example 1: flex-grow: 0 (no growth)
.item { flex-grow: 0; }

3. flex-shrink (Shrinking)
flex-shrink controls how much an item shrinks when space is tight. Higher number = shrinks more. Default is 1 (all shrink equally).
Example 1: flex-shrink: 1 (all shrink equally - default)
.item { flex-shrink: 1; flex-basis: 150px; } Container is narrow (300px) - items must shrink!
1

Example 2: flex-shrink: 0 (doesn't shrink - overflows)
.item { flex-shrink: 0; flex-basis: 150px; }
0
0
Items with flex-shrink: 0 keep their size and overflow the container!
4. flex (Shorthand)
flex is a quick way to set flex-grow, flex-shrink, and flex-basis all at once.

flex: [grow] [shrink] [basis]
Example 1: flex: 1 (equal columns)
.item { flex: 1; } /* Same as: flex-grow: 1, flex-shrink: 1, flex-basis: 0 */
